In this lab, K-Means Clustering was applied to study customer credit card behavior and identify different customer groups. The dataset was prepared by removing unnecessary columns such as CUST_ID and treating missing values to improve data quality. Then, the data was normalized using StandardScaler before building the clustering model.

To find the most suitable number of clusters, the elbow method and silhouette score were evaluated, and the optimal value was K = 4. The clustering results showed clear differences between customers based on their spending patterns, balances, and cash advance activities. In the final step, Principal Component Analysis (PCA) was used to visualize the clusters and make the customer segments easier to interpret and analyze.
